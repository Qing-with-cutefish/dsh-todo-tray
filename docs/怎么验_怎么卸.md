## 零、0.3.12 ~ 0.3.14 新增功能怎么验（约 6 分钟）

> 本页主体写于 0.3.4 时代，基础操作仍然适用；0.3.5 ~ 0.3.12 的变化按小节补在这里。

**1）新建清单**

1. 在桌面新建一个空文件夹，比如 `桌面\试验清单`。
2. 右键托盘图标 → **新建清单…**（或面板顶部清单下拉的最后一项 **＋ 新建清单…**）。
3. 点 `选择…` 选刚才那个文件夹（清单名会自动带成文件夹名）→ 点 **新建**。
4. 预期：面板下拉里多出这个清单并已选中，列表是空的；点 `＋ 新增` 加一条，只出现在这个清单里。
5. 拒绝场景：对着同一个文件夹再建一次 → 红字「这个文件夹已经是清单了」，不写任何文件。

**2）冒泡跟随清单**

1. 面板下拉选「我的待办」→ 等 15~60 秒，冒泡只冒这个清单里的事项。
2. 切到新建的那个清单（里面只有你刚加的一条）→ 冒泡只冒它。
3. 切回「全部清单」→ 两个清单的事项会轮流冒。
4. 切换清单的一瞬间：旧气泡立刻收起，新的从 3★ 重新轮。

**3）清单改名 / 移除（0.3.13）**

1. 清单下拉最后一项 **⚙ 清单管理…**（托盘右键也有「清单管理…」）。
2. 列表里选中「试验清单」→ 名称框改成新名字 → **改名**：下拉里的名字立刻跟着变。
3. 点 **移除** → 系统确认框（写明数据文件路径）→ 是：清单从下拉消失，数据文件还在原处。
4. 只剩一个清单时点移除 → 红字「至少保留一个清单」。

> 移除只改 `config.json` 的 `lists[]`，**不删数据文件**；要彻底删就自己删那个 `.todo\todos.json`。

**4）侧边收起箭头 + 小鲸鱼右键（0.3.14）**

1. 点小鲸鱼展开面板 → 右上角**没有 ×**；面板**右侧贴着屏幕右沿**，**左侧中间**多出一个白色小竖条 + 蓝色 ▶ 箭头（朝面板/屏幕右边），整块露在面板外。
2. 拖一下面板 → 箭头跟着走；点箭头 → 面板收回成小鲸鱼。
3. 右键小鲸鱼 → 菜单里有「关闭小鲸鱼」（只留托盘图标）和「退出待办托盘」。
4. 冒泡只在收起态：点小鲸鱼展开主界面 → 正在冒的气泡立刻收，之后不再冒；点箭头收回小鲸鱼 → 15~60 秒后恢复冒泡；面板和小鲸鱼都关掉 → 也不冒。
5. 从托盘图标直接打开面板 → 右上角恢复成 ×（这条路径没变）。
6. 纵向对齐：小鲸鱼在屏幕中间时展开 → 面板与它垂直居中；把鲸鱼拖到最上/最下再点开 → 面板顶/底贴任务栏。
7. 箭头不残留：点小鲸鱼展开 → 把面板拖到屏幕边收成小鲸鱼 → 侧边的箭头应该一起消失（不再留在原地）。
8. 拖动起手：按住面板标题条往屏幕边拖 → 收成侧边条的位置应该从**面板原来的中心**开始，而不是跳到鼠标那一点；继续上下拖，条按鼠标位移走；推到最上/最下，条贴住工作区顶/底，鼠标可以再往外推。
9. 收回保持原位：把小鲸鱼拖到屏幕最底下松手 → 点一下打开面板 → 点收起箭头 → 小鲸鱼应回到**最底下**（它自己的位置，不再被拉回面板中心）。
10. 只能拖小鲸鱼：按住小鲸鱼上下拖=定位，松手固定；单击=打开主界面；拖面板标题条应该**不动**（右下角抓手仍能缩放）。
11. 换边动画：拖着小鲸鱼横向过屏幕中线 → 鲸鱼应该"嗖"一下滑到另一侧的屏幕边（拖的过程中就换，不用松手）。
12. 弹出/缩回动画：点小鲸鱼 → 鲸鱼消失的同一瞬间主界面从屏边滑入；点收起箭头 → 主界面先滑出屏边再消失。
13. 卷帘出现：点小鲸鱼 → 滑入时列表是**空白**的；滑进来之后，事项从第一条开始、从上往下一条条铺出来（75 条约 1.3 秒），每行出现时带一点淡入。
14. 侧边面板不穿透（0.3.26）：点小鲸鱼展开 → 鼠标移上去**立刻能点**，不用等悬停；标题条拖不动（只能拖小鲸鱼）。
15. 图钉（0.3.26）：点顶栏图钉（编辑和 × 之间，灰色）→ 变蓝并固定在当前，面板不再收回侧边栏；这时鼠标要悬停 1.5 秒（0.3.27 起可调）才变可点，标题条可以拖，拖动**不会出屏幕**、碰到边就顶住、两面都顶死就不动。再点一下图钉 → 取消固定、收回小鲸鱼。
16. 悬停时间可调（0.3.27）：设置 →「数据」区右边有「悬停进交互 [1500] 毫秒」，改成 800 / 1200 / 1500 试手感，点关闭即生效、记在 config 里。
17. 悬停零反馈（0.3.28）：钉住面板后鼠标移上去，**界面上什么都不要变**（没有浅色边框）；到 1.5 秒那一刻才出现实线边框并变得完全不透明；移开 1.5 秒后恢复原来的透明度。
18. 透明度分模式（0.3.29）：不钉住时（点小鲸鱼弹出的面板）**永远 100% 不透明**，设置里的透明度对它无效；只有钉住后的浮窗才用那个透明度（悬停到点仍是 100%）。
19. 0.3.30 修复：①不钉住时侧边面板**真的** 100% 不透明（之前会被 Stop-AutoHide 改回 30%）；②点完按钮不再留虚线黑框。
20. 0.3.31 修复：点设置 → 改点什么 → 点关闭，主界面**不应该自己消失**（以前会被"展开后 3 秒自动收回"收走）。

> 箭头贴哪边由面板位置决定：面板在屏幕左半边贴左边、右半边贴右边，箭头始终朝屏幕外。

## 一、先看测试版（不碰你真实待办）

双击 **`start-dev-test.cmd`**。数据只读写这个文件夹里的 `data\`。

**应该看到：**

1. 任务栏右下角出现托盘图标：
   - 0 条 = 灰色圆圈 + 白勾；有 N 条 = 橙底白数字；**≥10 条变红底**；超过 99 显示 `99`
   - 鼠标悬停显示 `待办 N 条（逾期 M）｜最近到期 10-28 21:00`
2. 启动时**右下角弹出一张小窗**（深色卡片 + 左侧橙条）「补提醒 · 有 N 条待办到期」——种子里有 2 条过期，所以第一次启动必有；第二次启动不会再弹（已提醒过）。**点小窗直接打开面板**，8 秒自动消失，且不抢键盘焦点
3. **左键点图标** → 右上角浮出面板：
   - 顶部：`全部清单` 下拉 + 搜索框
   - 每条：标题 + `逾期/到期/完成 时间` + `#标签`（逾期红字，完成灰字划线）
   - **0.2.1 起**：3★ 行是**红底 + 左侧红条**、2★ 是**黄底 + 左侧黄条**、1★ 白底；星星只在弹窗里，列表不画星星
   - 排序：**3★ 组 → 2★ 组 → 1★ 组**，组内按你添加的先后；**不再按到期时间重排**
   - 底部：`＋ 新增` / `导出 ▾` / `刷新` / `设置`（「打开数据文件夹」移到 设置 里）
4. **＋ 新增** → 弹框：填标题、到期（可空，支持 `10-28 21:00` 这种简写）、**紧急（1★/2★/3★）** → 确定 → 列表里立刻出现
   - **名额**：3★ 同时只能 1 个、2★ 最多 2 个；满了该项会**置灰**并提示「请先取消现有的」
4.5 **设置**（0.2.0）：面板底部 `设置` 或右键 `设置…`
   - **常驻悬浮**：面板钉在右上角（距边 12px）、置顶、**不自动消失**、不抢焦点
   - **N 秒后自动隐藏**：5 / 15 / 30 / 60 秒，默认 15；到点淡出收起，日志里有 `自动隐藏到点`
   - **透明度** 30%~100%（常驻默认 85%，自动隐藏默认 100%）、**置顶**勾选
   - 点「关闭」即生效；会写进 `config.json` 的 `ui` 段（只加这一段，不动清单）
5. **到期提醒**：新增一条 2 分钟后到期的，等一会儿 → 右下角弹出小窗「待办到期 / 标题（10-28 21:05）」
   （提前量在 `data\config.json` 的 `notify.aheadMinutes`；测试种子是 5 分钟）
6. 勾选 / 点行内任意处 → 计数 −1、`data\todos.json` 同步
7. 搜索框输入几个字 → 列表实时过滤；清空恢复（**搜英文/数字先切英文输入法**，否则中文输入法会先吃掉一次按键）
8. 点面板外 / `Esc` / `×` → 收起（`×` 只收界面，托盘还在；真退出走右键）
9. **右键图标**：显示待办 / 立即刷新 / 新增待办 / 打开数据文件夹 / 设置… / 开机自启（启动文件夹）/ 版本 / 退出
9.5 **导出（0.2.3）**：底栏 `导出 ▾` → 小窗选「导出已完成事项（N）」或「导出全部清单（N）」，
   格式可选 **CSV / Excel**；默认存到 `文档\待办导出\`，CSV 用 Excel 双击不乱码，导出包含已从列表消失的完成项
10. **编辑态（0.2.2）**：点面板右上角 `[编辑]` → 顶栏变 `[完成]`，每行变 `☰ 标题 N★ [⚙] [🗑]`，**到期时间暂时隐藏**
    - **拖动**：按住 `☰` 上下拖，**只有同一星级内能拖**；拖到别的星组会变禁止光标、松手回原位并提示
    - **改星级**：点 `⚙` → 同一个弹窗（标题变「编辑待办」）→ 改 1★/2★/3★ → 保存后自动归位
    - **删除**：点 `🗑` → 二次确认 `删除「xxx」？此操作不可撤销。` → 点「删除」后条目真没了（不是变灰）
    - 点 `[完成]` 或收起面板，回到常态样式

> **Win11 注意**：新装的托盘图标默认被塞进右下角的 **`^` 溢出区**，第一次可能看不见。
> 点 `^` 找到它、拖到外面即可；或「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里打开。
> （程序不写注册表，所以不能替你强开。）
> 小技巧：**再双击一次 `start-dev-test.cmd`**，已开着的面板会被叫出来，不用去溢出区找图标。

## 二、怎么卸 / 怎么退

- **退出**：右键托盘图标 → `退出`。图标立刻消失，进程结束，不留后台。
- **彻底卸载**：退出后删掉整个文件夹。没有注册表项、没有服务。
- **开机自启已开的话**：先右键取消勾选（或手动删掉 `shell:startup` 里的 `dsh-todo-tray.cmd`）。
- **找不到图标时**：任务管理器结束 `powershell.exe`（先确认没有别的 PS 任务在跑）。

## 三、确认没问题后转正式版

双击 **`start-todo-tray.cmd`**（没有黑窗口）。

搜 `conhost` 最多一个，且它**没有窗口、不在任务栏**（那是 PowerShell 的控制台宿主，看不见也点不到）。

`start "" powershell -WindowStyle Hidden`，改回 `wscript start-todo-tray.vbs`。

- 数据在 `%USERPROFILE%\.dsh\deepseek-todo\`：`config.json`（清单+提醒设置）、`todos.json`、`state.json`（已提醒记录）、`logs\`

## 六、命令行 todo.cmd（v1-c，给 agent / 批处理用）

同一份数据，托盘和 CLI 都能读写（有文件锁，不会互相覆盖）。

```
:: 给某个工作区建清单（会建 .todo\ 和 AGENTS.md 指针，并登记到托盘）
todo.cmd init --workspace C:\work\myproject

:: 加 / 看 / 完成 / 删 / 导出
todo.cmd add "补 304 材质" --due "10-30 09:00" --tags 紧固件 --link "C:\work\myproject\notes\x.md"
todo.cmd list
todo.cmd list --all
todo.cmd done sw-015
todo.cmd rm sw-019
todo.cmd export --md
todo.cmd where
```

- 清单怎么选：`--scope <id>` > 从当前目录往上找 `.todo\` > 全局「我的待办」
- 到期时间支持 `2026-10-30 09:00` 或 `10-30 09:00` 简写
- 退出码：0 成功 / 1 业务失败 / 2 用法错误
- 试完想撤销：删掉那个目录的 `.todo\`，再编辑 `config.json` 的 `lists[]` 去掉那一条（或不管它，托盘会显示为「文件不存在」的黄条）

## 七、浮窗交互怎么验（5 分钟）

> 默认尺寸 **420×560**，首次启动位置在**右上角、距屏幕边 12px**（旧 config 没有 `ui.window` 时按这个来）。

| 要验的 | 怎么做 | 应该看到 |
|---|---|---|
| 穿透 | 面板在屏幕上时，用鼠标**直接点面板中间** | 点到的**是下面那个窗口**（记事本/画图），面板不动；面板无边框 |
| 悬停进交互 | 鼠标停在面板上 **0.6 秒**（先出现浅蓝细边框，再到点变实蓝边框） | 边框变实蓝，此时能点列表 |
| 回穿透 | 鼠标移开面板 **1.5 秒** | 蓝边框消失，再点又穿到下面窗口 |
| 点得到（0.3.3 新增） | 交互态下点**底栏按钮之间的空白**（「导出 ▾」和「刷新」中间那一段），再点**右下角抓手** | 「空白处」不穿透到桌面（点下去面板还在）；抓手能拖动缩放 |
| 拖动 | 交互态下按住**标题那行**（「待办 N 条」文字或旁边的空白）拖 | 窗口跟着走；松手后位置记住（重启还在） |
| 缩放 | 拖**右下角** | 可大可小，**最小 320×240**（再拖就拖不动） |
| 吸边 + 小鲸鱼 | 把窗口拖到**屏幕左/右边缘 10px 内**松手 | 自动吸边并收成 **24px 宽**小鲸鱼；**0.3.4 起小鲸鱼真的画出来**（蓝色 24×72，不再是空白） |
| 展开 / 自动收 | 点小鲸鱼 | 整窗展开（保持透明度和位置），**约 3 秒**后自己收回小鲸鱼 |
| 鲸鱼重启可点（0.3.4） | 首页收起状态（`collapsed=true`）重启程序，再点小鲸鱼 | 整窗展开；不是"点了没反应"（0.3.3 的 B-②） |
| 抗 Win+D | 按 **Win+D**（显示桌面）3 次 | 待办窗**仍在桌面上**（不会跟着最小化） |
| 不进 Alt+Tab | 按 **Alt+Tab** 按住不放 | 列表里**没有**「待办」这一项 |
| 老配置不崩 | 用 0.2.3b 的 `config.json`（没有 `ui.window`）启动 | 正常启动，面板在右上角；**拖动/收起后**才写 `ui.window` |

- 小鲸鱼是**独立小窗**（不是托盘图标），位置记在 `config.json` 的 `ui.window`；
  想改自动收回时长：设置 → 「侧边收回」选 0/3/10 秒。
- 运行时会有 1 个**不可见的 conhost**，属正常现象（0.2.0 起就这样，不是 bug）。
- 自检：双击 `selftest.cmd`，0.3.40 应打印 `结果: 266 项通过, 0 项失败`。
