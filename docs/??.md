## 1 它是什么、给谁用

常驻 Windows 托盘的待办清单程序：点开是一张悬浮清单，收起是屏幕边上一只小鲸鱼。给人 + 多个 AI agent 在同一台工作电脑上协作用——agent 用 `todo.cmd` 把待办写进工作区 `.todo\todos.json`，人从托盘/鲸鱼看、勾、编辑、导出。
设计第一原则：**不认文件名，只认 `config.json` 的 `lists[]`/scope**（用户原话：换一个对话框或换一个用户，她的待办事项就不叫这个名字）。
不适用：要多设备/云同步或团队共享（不支持，纯本地）；多屏 / 高 DPI / 任务栏在侧边（未适配，100% 单屏已验证）；没有 PowerShell 5.1 的机器；想「装完就忘」的人（Win11 会把新托盘图标收进 `^` 溢出区，要手动拖出来）。

## 2 为什么长成这样

1. **数据放 `%USERPROFILE%\.dsh\deepseek-todo\`，不放程序目录**——用户定的：数据目录必须在 DSH 安装目录之外（升级会替换安装目录）；`AGENTS.md` 同条硬约束「工作区/数据绝不能放在 DSH 安装目录」。副作用是换机器=拷这一个文件夹。
2. **PowerShell 5.1 + WinForms，不编译、不装运行时**——设计说明 §2/§7：零依赖、不用编译，只要 Windows 自带 .NET Framework；启动卡硬约束「本机没有 pwsh，只用 powershell.exe」。代价全在开发笔记 §三的 12 个 PS 5.1 坑（脚本块闭包、空数组、`ConvertTo-Json` 转义中文、线程池 Timer 回调不执行…）。
3. **启动用 wscript + `.vbs`，不用 `.cmd` 或 `-WindowStyle Hidden`**——用户反馈 R1「不要黑框」；Q8 原话要点「允许一闪，但不能留下常驻窗口/任务栏条目」：内存不够时系统会关「不用的窗口」，留着会误关托盘。0.2.0 复现到 Win11 控制台宿主是 Windows Terminal，`SW_HIDE` 对它无效。
4. **不写注册表，也就不去强开托盘图标**——用户 2026-10-27 定的开发规范「不写系统目录、不写注册表、不联网」；Win11 把新图标塞进 `^`，只能启动气泡提示 +「再双击一次 `.cmd` 让已运行实例弹面板」兜底（开发笔记 ⑧）。
5. **到期提醒自绘小窗，不用 `ShowBalloonTip`**——Win11 26200 会吞掉气泡，河豚用独立最小脚本复现（开发笔记 ⑦）；小窗放右上角（右下角被「激活 Windows」水印盖住）、`WS_EX_NOACTIVATE` 不抢键盘焦点。
6. **悬浮窗分穿透态/交互态，透明度与鼠标穿透分开**——用户反馈：设了透明度但鼠标还能点到，容易误触。透明度只影响外观，鼠标穿透要单独 `WS_EX_TRANSPARENT`；进交互=托盘图标或悬停（Q1 拍板；悬停时长后来从 0.6 秒调到 3 秒）。
7. **小鲸鱼侧边收起是用户点名要的**（2026-10-28 15:33 反馈 3；Q4 拍板「屏幕上独立的小鲸鱼、默认右侧、左右可设」；Q5 拍板展开后 3 秒自动收回）。**边缘吸附/拖动**是需求草案 B 节我们提的方案，用户 15:44 拍板 6 问后整份草案定稿为基线。
8. **写盘自写序列化 + 文件锁 + 原子替换**——PS 5.1 的 `ConvertTo-Json` 会把中文转义、缩进风格也不对（开发笔记 ⑤）；CLI 和面板会同时写，所以先锁后写、临时文件替换，写前 re-parse 比对条数。河豚实测 8 个 `add` 同时打不丢。
9. **单实例用命名事件唤出已运行实例**——托盘图标在 `^` 溢出区不好点（开发笔记 ⑧）；重复启动不再静默退出。这条「唤出」入口后来正是 sw-051 的现场。
10. **7000 行按 19 模块重排**——用户 2026-11-10 要求整理代码；函数体逐字节未改、只动组织方式（AST 逐函数比对 150 个，0 差异），自检 250/250 防退化。
